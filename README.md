From C# to Go (Golang) – Completed Project

Coming from a strong background in C# and .NET, I was excited to dive into Go (Golang) and explore its capabilities. 
What stood out to me was Go’s simplicity, performance, and how seamlessly it handles API development. 
Due to its familiar concepts like structures and interfaces, adapting to Go felt intuitive, enabling me to quickly build a fully functional REST API.

I also applied Clean Architecture principles, structuring the code into separate layers for Controllers, Services, 
and Repositories—an approach I frequently use in C#/.NET that worked just as well in Go!

For this project, I used:
✅ Gin – A lightweight and fast HTTP framework
✅ GORM – ORM for database interactions
✅ Golang Migrations – For managing database schema changes
✅ Swagger – For API documentation and testing
